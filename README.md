# Cookie Consent - GTM Community Template Gallery

This repository holds the Google Tag Manager template of the
[68publishers/cookie-consent](https://github.com/68publishers/cookie-consent) package,
in the layout required by the [Community Template Gallery](https://developers.google.com/tag-manager/templates/gallery).

`template.tpl` is a copy of [`gtm_template.tpl`](https://github.com/68publishers/cookie-consent/blob/main/gtm_template.tpl)
from the main repository. Do not edit it here - open a pull request against the main repository instead.
The `Sync template` workflow copies the file over after each release.

Documentation for the template lives in the
[main README](https://github.com/68publishers/cookie-consent#integration-into-the-gtm).
